# Python
СОДЕРЖИМОЕ ПРОЕКТА

Проект содержит 2 теста:
1. Тест калькулятора с задержкой вывода результата
2. Тест размещения заказа в корзине

ЗАПУСК ТЕСТОВ ДЛЯ ФОРМИРОВАНИЯ ОТЧЕТА

Для запуска тестов необходимо:
1. Клонировать папку lesson_10
2. Перейти в папку проекта командой:
    cd lesson_10
3. Подключить в папку с проектом allure командой:
    pip install allure-pytest
4. Запустить тесты и сохранить результаты их выполнения в папку allure-results командой:
     python -m pytest --alluredir allure-results

ПРОСМОТР СФОРМИРОВАННОГО ОТЧЕТА

Для формирования и последующего просмотра отчета ввести команду
    allure serve allure-results
